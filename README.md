# Поиск и анализ не-мест в городской среде

## Этот проект предназначен для поиска не-мест в городской среде и оценки потенциала их развития.

Инструменты, с помощью которых была выполнена эта работа:

Программное обеспечение: 
QGis версии 3.40.6 и его модули: OSMDounloader, QuickOSM.

Облачная платформа: Colab Google. На языке Python 3
https://colab.research.google.com 
(требуется регистрация)

Облачное хранилище геоданных: Open Street Map https://www.openstreetmap.org/

## Данные, на которых проводилось исследование

Репозиторий содержит четыре папки: папки с данными (имеют в названии слово "data", папка с настройками для оформления и папка с иллюстрациями, полученными в результате работы метода. Коды, необходимые для работы метода, содержатся в блокнотах, несобранных в папки. Эти коды рекомендуется открывать с помощью платформы Google Colab. В случае запуска кодов на локальном устройстве понадобится дополнительная установка ряда библиотек.

- в папке data находятся необработанные данные, из которых при использовании блокнотов "Категории по тэгам OSM" и "Блокнот для подготовки данных перед обучением" можно получить данные для работы с моделями. Результаты работы с этими данными сохранены в следующую папку.

- в папке data_for_training находятся обработанные данные для обучения. Их можно сразу применять для тестирования моделей.
Модели на основе логистической регрессии и случайного леса представлены в блокнотах.

С целью получить более точные предсказания рекоммедуется использовать Randome Forest. Она находится в блокноте "Модель для экстраполяции результата на другие наборы данных". Её мы обучали на данных Московского района и экстраполировали на участки в Кировском и Невском районах.

Если требуется получить большее количество метрик для оценки, а также расчитанную вероятность принадлежности к предсказанному классу для каждого объекта, рекоммендуем испльзовать модель на основе логистической регрессии. Она находится в блокноте "Модель для получения коэффициентов значимости и оценки достоверности". Она обучалась на всём доступном массиве данных.

Важным шагом является сбор полевых данных. Он был выполнен без обработки с помощью языка Python.
