# Методика полевого исследования
## Краткое описание исследования
Для получения полевых данных были выполнены следующие шаги: 

1) Выбор полигонов апробации метода
2) Камеральный сбор данных
3) Подготовка материалов для исследования
4) Проведение исследования
5) Камеральная обработка данных

## Выбор полигона. Однородное районирование Санкт-Петербурга по типу морфологии застройки

Выбрать районы апробации помог код, предложенный здесь: https://docs.momepy.org/en/stable/examples/clustering.html. 
Мы сделали его более универсальным для разных городов и с его помощью обследовали все районы Санкт-Петербурга по очереди.
Код для выполнения этой задачи находится в блокноте "Морфология застройки". Вычислительные мощности всех устройств, на которых был проведён эксперимент, не позволили обследовать сразу весь город, поэтому код применялся отдельно для каждого района.

Так как не вышло создать алоритм, который создаст одну общую легенду для всех районов, то прямого соотвествия между легендами для разных административных районов. Мы получили только районы с морфологией застройки, одинаковые внутри. Пришлось вручную соотносить участки в разных административных районов с похожими и различными типами.

Так были выбраны три района: два похожих и один отличающийся.

## Исходные материалы

Набор карто-схем в масштабе, достаточном для отображения границ всех объектов (в том числе узких тротуаров, вазонов и иногда люков).

Чек-лист признаков безместности.

Требования к материалам:

- набор карт:
1) чёрные границы толщиной 0,01 и пустая или белая заливка
2) крупный масштаб, в котором даже мелкие объекты остаются не только читаемыми, но и доступными для закрашивания
3) числовое обозначение соседства листов карт

необходимо перед созданием отдельных листов разместить на основной карта-схеме сетку точек с единственным полем "id" или "fid", отменить отрисовку геометрии и добавить подписи по полю с уникальным номером. Затем нужно выбрать достаточно крупный формат чисел, чтобы они не перекрывали объекты и были заметны на карта-схеме. При разделенииосновной карта-схемы на отдельные листы нужно разделять её так, чтобы на каждом оказывалось минимум по 4 точки с числами.
5) любой носитель, с помощью которого можно "раскрасить карту" могласно легенде. Мы использовали два варианта: формата А4 с цветными карандашами и мобильное приложение Sketchbook. 
- чек-лист:
1) испоьзовали чек-лист, созданный в Гугл.Таблицах, где автоматически подсчитывалось количество набранных баллов. Можно использовать любой другой способ быстрого подсчёта.
   Адрес использованного чек-листа:
   https://docs.google.com/spreadsheets/d/1PCesGVlZXIxE5mQFJJDIZnFrRMNkWeBjKzkbCajvT2g/edit?gid=0#gid=0

### Описание подготовки материалов 
Перед исследованием с помощью плагина OSMDownloader были скачаны с OSM все полигональные объекты на территории каждого района. Затем с помощью модели мы преобразовали все полигоны в линиии и обратно в полигоны, чтобы избежать пересечения полигонов. Затем на поверхности каждого полигона была создана точка, точке присвоены атрибуты исходного полигона, в котором она находилась. Затем было применена очистка точечного GeodataFrame по значению поля "osm_id". Так получен точечный GeodataFrame без повторов объектов. После этого атрибуты полученных точек были присвоены ноавым полигонам. Так была достигнута максимальная точность переноса данных, доступная для простого алгоритма.

Для полевой работы потребуются лишь границы этих полигонов. Для упрощения последующей работы рекомендуется провести рассечение объектов по линиям, где линиями выступают объекты с линейной и полилинейной геометрией с ненулевым значением поля "barrier". Это повысит точность будущего предсказания на величину до 10%.

При работе испльзовали набор картосхем с границами 

## Процесс сбора данных

Исследование проводится в полевых условиях. Потребуются распечатанные листы бумаги и 2 карандаша разных цветов или 4 карандаша двух цветов разной интенсивности. В нашем случае использовались синий и серый карандаши, а разнообразие достигалось разным нажимом.

При непосредственном наблюдении каждый объект, отображённый на карте, получал оценку в соотвествии с чек-листом, указанным выше. Это позволило создать следующую легенду:

0 баллов - тёмно-серый цвет - безместность не выражена
1 балл - светло-серый цвет - безместность слабо выражена
2 балла - белый цвет - безместность оценена неоднозначно
3 балла - светло-синий цвет - безмесность выражена
4 балла - синий цыет - безместность сильно выражена
х баллов - белый цвет - объект не обследован

Результат работы: двухцветная карта-схема

## Камеральная обработка

Полевые данные были вручную перенесены в имевшиеся файлы формата .gpkg в новый столбец. В нашем случае он назывался «non-place1». Позднее для применения данных конкретно в нашем методе упрощены до двух категорий «non-place1» и «other». 

Non-plase - 3 или 4 балла,
Other - 0 или 1 балл.
