# Методика полевого исследования
## Краткое описание исследования
Для получения полевых данных были выполнены следующие шаги: 

1) Выбор полигонов апробации метода
2) Камеральный сбор данных
3) Подготовка материалов для исследования
4) Проведение исследования
5) Камеральная обработка данных

## Выбор полигона. Однородное районирование по типу морфологии застройки

Выбрать районы апробации помог код, предложенный здесь: https://docs.momepy.org/en/stable/examples/clustering.html. 
Мы сделали его более универсальным для разных городов и с его помощью обследовали все районы Санкт-Петербурга по очереди.
Код для выполнения этой задачи находится в блокноте "Морфология застройки". Вычислительные мощности всех устройств, на которых был проведён эксперимент, не позволили обследовать сразу весь город, поэтому код применялся отдельно для каждого раона.

Так как не вышло создать алоритм, который вычислит одну общую легенду для всех районов, то прямого соотвествия между цветами районов с разной морфологией застройки нет. Мы получили только районы с морфологией застройки, одинаковые внутри. Пришлось вручную соотносить участки в разных административных районов с похожими и различными типами.

Так были выбраны три района: два похожих и один отличающийся.

## Исходные материалы

Перед исследованием с помощью плагина OSMDownloader были скачаны с OSM все полигональные объекты на территории каждого района. Затем с помощью модели мы преобразовали все полигоны в линиии и обратно в полигоны, чтобы избежать пересечения полигонов. Затем на поверхности каждого полигона была создана точка, точке присвоены атрибуты исходного полигоны=а, в котором она находилась. Затем было применена очистка точечного GeodataFrame по значению поля 'osm_id'. Так получен точечный GeodataFrame без повторов объектов. После этого атрибуты полученных точек были присвоены ноавым полигонам. Так была достигнута максимальная точность переноса данных, доступная для простого алгоритма.
